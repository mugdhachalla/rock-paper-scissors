# Rock Paper Scissors Game 🎮

A simple Rock Paper Scissors game built using **HTML**, **CSS**, and **JavaScript**.

### Features
- Click to play: Rock, Paper, or Scissors
- Random computer choice each round
- Result shown instantly on screen
- Clean UI with hover effects
- Optimized for different screen sizes (responsive design)
- Real-time score tracking
- Reset button to start fresh anytime

### 🛠 Files
- `index.html`
- `style.css`
- `script.js`
- `README.md`

---

## How to run

### Run locally (VS Code Live Server)
1. Install the Live Server extension in VS Code.
2. Open this project folder in VS Code (File → Open Folder...).
3. Open `index.html`, then click the "Go Live" button at the bottom-right or right-click `index.html` → "Open with Live Server".
4. The site will open in your default browser (commonly at http://127.0.0.1:5500).
